# PedidoPronto

Uma demonstração de painel operacional para negócios que precisam acompanhar pedidos, produção, prazos e faturamento em uma visão só.

**O problema:** o dono precisa abrir planilhas, conversas e anotações para saber o que vence hoje.

**A demonstração:** um painel que concentra prioridades, etapas e atividade recente. Todos os dados são fictícios.
